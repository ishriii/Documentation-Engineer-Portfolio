# Overview
## Definition
A short introduction explaining what the API does and what it is used for.  
It helps developers quickly understand the purpose of the API.

# Base URL
## Definition
The root address of the API server that all endpoints use.  
Developers combine the base URL + endpoint path to form the full request URL.

# Endpoint
## Definition
A specific URL used to access a resource or perform an action.

# HTTP Method
## Definition
The action the client wants to perform on a resource.

## Common methods
| Method | Purpose               |
| ------ | --------------------- |
| GET    | Retrieve data         |
| POST   | Create data           |
| PUT    | Update/replace data   |
| PATCH  | Partially update data |
| DELETE | Remove data           |


# Headers
## Definition
Metadata sent with the request or response that provides additional information.  
| Header        | Purpose                    |
| ------------- | -------------------------- |
| Content-Type  | Format of the request body |
| Authorization | Authentication credentials |
| Accept        | Expected response format   |
